Cisco Umbrella, built on the OpenDNS platform Cisco acquired in 2015 and now sold within Cisco Secure Access, is Cisco's cloud-delivered security service: DNS-layer security, secure web gateway, cloud-delivered firewall, CASB (Cisco Cloudlock) and remote browser isolation. Cisco publishes a full OAuth 2.0 client-credentials REST API at api.umbrella.com, split into five scopes — admin, auth, deployments, investigate, policies and reports — and documents it under the Cloud Security section of Cisco DevNet, where 26 first-party OpenAPI 3.0 documents covering 256 operations are published for download. The surface spans key and user administration, MSP/provider consoles, network and tunnel deployment, roaming computers and virtual appliances, destination and application lists, DNS/web/firewall reporting, app discovery, and the Umbrella Investigate threat-intelligence API.

**Areas:** Security · DNS · Secure Web Gateway · Cloud Security · Zero Trust · Threat Intelligence · CASB · Firewall · Threat Investigation · Networking
